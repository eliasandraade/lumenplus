> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restaurar o Light Theme da Lumen+ para a paleta azul navy + cinzas neutros anterior ao CP3, alterando apenas os valores de `lightTokens` em `tokens.ts` em um único commit.

**Architecture:** Um único arquivo muda (`lumen_mobile/src/theme/tokens.ts`). Todos os nomes semânticos são preservados — apenas os valores de cor mudam.

**Tech Stack:** TypeScript, React Native, tokens semânticos light/dark já existentes.
