# F5.1 — Amanhã com o Emanuel + Card no Hub

**Data:** 2026-06-06  
**Status:** Implementado

---

## Objetivo

Permitir que o membro planeje espiritualmente o dia seguinte a partir do Projeto Semanal ativo, sem criar novos endpoints ou tabelas.

---

## Arquitetura

### Fonte de dados

- **Tabela:** `projeto_vida_semanal.plano_diario` (campo JSONB já existente)
- **Formato:** `{ "seg": { proposito, missa, horario_missa, oracao_manha, lectio, terco, leitura_espiritual, evangelizacao }, "ter": {...}, ... }`
- **Merge parcial:** `PUT /projeto-vida-semanal/{id}` com `{ plano_diario: { [dia]: values } }` — o backend faz merge por chave, preservando os outros dias.

### Endpoints utilizados (existentes)

| Método | Rota | Uso |
|--------|------|-----|
| GET | `/projeto-vida-semanal/{id}` | Carregar dados do dia ativo |
| PUT | `/projeto-vida-semanal/{id}` | Salvar planejamento do dia (merge parcial) |

Nenhum endpoint novo foi criado. Nenhuma migration foi criada.

---

## Componentes

### Tela: `lumen_mobile/app/vida/diario.tsx`

**Rota:** `/vida/diario?semanalId=<id>`

**Parâmetros:**
- `semanalId` (opcional) — ID do projeto semanal ativo

**Estados:**
- `diaAtivo` — dia da semana selecionado (default: dia seguinte ao atual)
- `diaData` — campos do plano para o dia ativo
- `loading`, `saving`, `error`

**Comportamento quando `semanalId` ausente:**  
Exibe mensagem clara e botão "Voltar" — sem acesso à formulário.

**Campos por dia:**
- Propósito do dia (textarea)
- Missa (switch + horário condicional)
- Oração da manhã (input)
- Lectio Divina (input)
- Terço (switch)
- Leitura Espiritual (input)
- Evangelização (input)

**Navegação entre dias:** chips horizontais com os 7 dias da semana. Trocar de dia recarrega os dados do semanal e descarta edições não salvas do dia anterior.

**Salvar:** `updateSemanal(semanalId, { plano_diario: { [diaAtivo]: diaData } })` — garante que salvar um dia não sobrescreve os outros.

---

### Card no Hub de Vida: `lumen_mobile/app/vida/index.tsx`

**Condição de exibição:** `projeto !== null && semanalAtual !== null`

Aparece abaixo do card de ciclo ativo (ou dos botões de ação), mostrando:
- Ícone `moon-outline`
- Título: "Amanhã com o Emanuel"
- Subtítulo: "Planeje o dia de amanhã"
- Navega para `/vida/diario?semanalId={semanalAtual.id}`

Não aparece quando não há ciclo ativo ou quando não há projeto semanal criado.

---

## Regras respeitadas

1. Sem migration — usa `plano_diario` já existente.
2. Sem novo endpoint — usa GET/PUT do semanal.
3. Merge parcial por dia — backend preserva os outros dias.
4. Sem ciclo/semanal: mensagem clara na tela, card oculto no hub.
5. Sem métricas, contadores ou gamificação.
6. Tom contemplativo e simples.
7. Sem emojis.
