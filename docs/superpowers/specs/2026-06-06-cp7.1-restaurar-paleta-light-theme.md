# CP7.1 — Restaurar Paleta Light Theme Original

**Data:** 2026-06-06  
**Status:** Aguardando aprovação  
**Origem:** Feedback pós-deploy CP7 — Light Theme ficou ruim após o redesign  
**Tipo:** Frontend only — sem backend, sem migration, sem endpoint novo

---

## Problema

O Light Theme atual — introduzido no CP3 ("Caderno de Oração") — usa uma paleta teal + neutrals com tint azulado projetada visualmente como "Vela em catedral". Com o toggle Dark/Light adicionado no CP7, o Light Theme ficou exposto ao contraste e apresentou problema visual: a paleta parece fria, dessaturada e inconsistente com a identidade original da Lumen+.

O Dark Theme está bem e não deve ser tocado.

---

## Causa

O CP3 substituiu integralmente o sistema de cores da Lumen+:

| Aspecto | Antes do CP3 | Depois do CP3 (atual) |
|---------|-------------|----------------------|
| Cor primária | Azul `#0066e6` / `#1a365d` | Teal `#1A859B` |
| Backgrounds | Brancos e cinzas puros | Brancos com tint azulado (`#f7f9fc`, `#eef2f7`) |
| Texto secundário | Cinzas neutros (`#737373`) | Azul-cinza (`#3d5166`, `#7a90a4`) |
| Bordas | Cinzas neutros (`#e5e5e5`, `#d4d4d4`) | Azul-cinza (`#dde6ef`, `#b8cdd9`) |
| Neutrals | Cinzas puros sem hue | Cinzas com hue azulado |

**Restrição importante:** A paleta original ("initial commit") não tinha sistema semântico — era um arquivo plano de cores estáticas. O CP3 criou o sistema `lightTokens`/`darkTokens`. A restauração deve preservar a estrutura semântica (necessária para dark mode e CP7) e apenas substituir os valores de cor no bloco `lightTokens`.

---

## Arquivo afetado

| Arquivo | Mudança |
|---------|---------|
| `lumen_mobile/src/theme/tokens.ts` | Substituir valores do bloco `lightTokens` — preservar `darkTokens` intacto |

Nenhum outro arquivo precisa ser alterado. Os componentes e telas consomem `lightTokens` via `useTheme()` → `t` — a troca de valores é transparente.

## Estratégia de implementação

### Passo 1 — Adicionar primitivos navy e neutralGray em `tokens.ts`

Adicionar dentro do objeto `primitives` (sem remover os existentes):
- `primitives.navy` — ramp de azul navy original
- `primitives.neutralGray` — ramp de cinzas puros sem hue

### Passo 2 — Atualizar `lightTokens` em `tokens.ts`

Substituir os valores de cor de `lightTokens` usando `primitives.navy` e `primitives.neutralGray`. O bloco `darkTokens` não é tocado em nenhuma linha.

### Passo 3 — Typecheck

```bash
cd lumen_mobile && npx tsc --noEmit 2>&1 | grep "tokens\|theme" | head -10
```

Esperado: zero erros (mudança de valores, não de tipos — a estrutura é idêntica).

### Passo 4 — Deploy

Push para GitHub → Vercel auto-deploy.
