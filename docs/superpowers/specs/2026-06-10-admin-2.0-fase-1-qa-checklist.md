## 1. Menu Admin (`/admin`)
- [ ] 🔴 Item **"Aprovações"** aparece na seção **Segurança** (abaixo de "Logs de Auditoria"), com descrição "Exportações aguardando aprovação".
- [ ] 🔴 Tocar em "Aprovações" abre a tela correta (não erro/tela branca).
- [ ] 🔴 Demais itens seguem visíveis: Dashboard, Criar Aviso, Avisos Enviados, Retiros, Entidades, Gestão de Usuários, Logs de Auditoria.
- [ ] 🟡 (Se tiver conta **ANALISTA** à mão) ela continua vendo **apenas Dashboard** — Aprovações **não** deve aparecer para ela.

## 2. Dashboard Admin (`/admin/dashboard`)
**Linguagem e cabeçalho**
- [ ] 🔴 Subtítulo do topo é **"Panorama da comunidade"** (não "Visão geral do aplicativo").
- [ ] 🟡 Seções com linguagem pastoral: "Membros", "Vínculos e participação", "Acompanhamento e interesse", "Ministérios com mais membros".

**Membros**
- [ ] 🔴 Card **"Membros ativos"** com número.
- [ ] 🔴 Card de cadastro no formato **"X de Y"** com o percentual no rótulo (ex.: "Cadastros completos (87%)").
- [ ] 🟡 Cards "Novos (7 dias)" e "Novos (30 dias)".

**Convites** (o item mais importante desta fase)
- [ ] 🔴 Seis contadores: Total, Aceitos, Pendentes, Recusados, **Expirados**, **Cancelados**.
- [ ] 🔴 **Reconciliação:** Aceitos + Pendentes + Recusados + Expirados + Cancelados = **Total**.
- [ ] 🔴 Rótulo da taxa = **"Convites aceitos (entre os respondidos): Z%"** (não "Taxa de aceitação" sobre o total).

**Percentuais com base**
- [ ] 🔴 Estado de Vida / Realidade Vocacional / Estado Civil exibem **"X de N (Z%)"** e rodapé **"de N membros que informaram"**.
- [ ] 🔴 "Acompanhamento e interesse" mostra **"X de Y"** com o percentual (não número solto).
- [ ] 🟡 Faixas Etárias: barras + linha separada **"Não informado"** + nota "Percentuais sobre N… que informaram a data de nascimento".

**Vínculos × pessoas**
- [ ] 🔴 "Vínculos e participação" mostra **duas linhas distintas**: "Pessoas participando" e "Vínculos ativos".
- [ ] 🟡 Nota explicativa "Uma pessoa pode servir em mais de uma comunidade…".
- [ ] 🟡 Coerência: "Pessoas participando" **≤** "Vínculos ativos".

**Top ministérios e geografia**
- [ ] 🔴 "Ministérios com mais membros" sem agrupamento estranho; ministérios de mesmo nome aparecem desambiguados por **"· Setor"** (se houver homônimos).
- [ ] 🟡 Nota "Contagem de pessoas (não de vínculos)".
- [ ] 🔴 Geografia **sem linhas em branco**; pode aparecer "Outras (n cidades)"; cidades capitalizadas e sem duplicatas de caixa (ex.: só "Fortaleza", não "fortaleza"/"FORTALEZA" separados).

**Geral**
- [ ] 🔴 Pull-to-refresh recarrega sem erro; nenhum erro no console.

## 3. Logs de Auditoria (`/admin/audit-logs`)
- [ ] 🔴 Ações reais aparecem com **rótulos amigáveis em pt-BR** (ex.: "Membro removido", "Cargo de membro alterado", "Perfil completo visualizado", "Exportação solicitada/aprovada").
- [ ] 🟡 Não aparecem rótulos de ações inexistentes (não deve haver entradas "fantasma" tipo convite aceito/recusado que o sistema não emite).
- [ ] 🟡 Códigos crus (ex.: `VIEW_FULL_PROFILE`) só aparecem como fallback raro, não como regra.
- [ ] 🔴 **Nenhum CPF/RG** visível no conteúdo dos logs (ids de entidade truncados; sem documento descriptografado).
- [ ] 🔴 Layout legível (cards, data/hora, ator quando houver).
- [ ] 🟡 Filtro por ação e "carregar mais" funcionam.

## 4. Aprovações (`/admin/approvals`) — foco web
- [ ] 🔴 Tela abre pelo menu (Segurança → Aprovações).
- [ ] 🔴 Em uma solicitação **pendente**, tocar **Aprovar** abre **modal inline** (não alerta nativo do navegador).
- [ ] 🔴 Tocar **Rejeitar** abre o modal inline correspondente.
- [ ] 🔴 **Não** aparece pop-up nativo do browser (confirma que `Alert.alert` foi removido).
- [ ] 🔴 Botão **Cancelar** fecha o modal sem ação.
- [ ] 🔴 Confirmar (Aprovar/Rejeitar) executa, mostra spinner e atualiza a lista; erro (se houver) aparece **dentro do modal**, não como alerta.
- [ ] 🔴 **Nenhum erro no console** durante o fluxo.
- [ ] 🟡 Se não houver solicitações, mostra estado vazio ("Nenhuma solicitação") sem quebrar.
